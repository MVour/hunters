# Cards (DRAFT, for review)

A first draft of the card set, following the rules in RULES.md. Edit freely:
change names, numbers, delete or add cards. Once it's agreed, this file is
what gets turned into data in `Global.deck`.

- **Green: questions.** The drawer reads it secretly and gives it to
  another player. That player reads it secretly and must react truthfully
  for their faction. The game applies the effect automatically (the server
  knows everyone's species), so nobody can lie by mistake. Only the giver
  and the receiver see the card; everyone sees the result (damage, a card
  changing hands...).
- **Red: hostile.** Events and equipment that cause damage, sometimes to
  the drawer too.
- **Blue: helpful.** Events and equipment that never hurt you.
- **Events** marked **(must)** happen immediately; the others are optional.
- **Equipment** stays face-up in front of its owner and is always active.
