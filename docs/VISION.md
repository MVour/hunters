## What it is
A hidden-role board game (vampires, werewolves, humans) in Godot, for the
user to play remotely with friends. Each player secretly gets a character,
moves around six forest locations, draws cards, attacks, and tries to win
for their side.

## Who it's for
The user and their friends, Greek and English speakers. Solo hobby project:
Claude writes the code; the user designs, draws, tests and steers.

## Success looks like
- A full game night over the internet with friends, without bugs that stop play.
- It feels like *their* game: their art, their rules, their cards, both languages.
- It's fun to watch: animations and feel matter.

## Not in scope (for now)
- A public release, store page, monetisation.
- A dedicated server or matchmaking service (the code is ready for one, but it's not planned).
- Recreating any existing commercial game's content.
